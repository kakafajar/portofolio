MODUL UI & DASHBOARD

Tampilan Utama (Home Interface)

Deskripsi Modul Home

Halaman awal game dirancang cerah dan ramah anak agar dapat langsung menarik minat pemain. Beranda ini menyediakan akses mudah ke semua fitur utama game seperti memilih mode permainan, mengonfigurasi timer dan audio, serta melihat papan skor tertinggi.

Fitur & Komponen Utama

  • Tombol Mainkan: Membuka modal navigasi pemilihan mode permainan.
  • Leaderboard Interaktif: Menampilkan peringkat skor tertinggi berdasarkan mode permainan yang tersimpan di LocalStorage.
  • Settings Modal: Opsi penyesuaian durasi waktu timer (misal: 30s, 60s, 90s) dan pengaktifan/penonaktifan suara game.
  • Panduan Edukasi: Edukasi dasar perbedaan jenis sampah (Organik, Anorganik, B3) sebelum memulai.
MODUL GAME LOGIC

Pemilihan Mode Permainan

Penjelasan Mode Permainan

Untuk memberikan variasi dan menjaga ketertarikan pemain, game ini menyediakan 3 mode permainan dengan gaya interaksi dan tantangan yang berbeda:

Mode Geser & Lepas

Pemain menyeret (drag) item sampah ke tempat sampah yang sesuai (Organik/Anorganik/B3) secara manual.

Mode Pilihan Ganda

Kuis pertanyaan cepat dengan opsi pilihan tempat sampah yang menguji kecepatan berpikir dan hafalan kategori sampah.

Sampah Berserakan

Beberapa jenis sampah muncul secara acak di area lapangan hijau dan pemain harus memilahnya sebelum waktu habis.

MODUL GAMEPLAY ENGINE

Arena Gameplay Permainan

Mekanisme Game & Pengalaman Bermain

Arena permainan didesain dengan feedback visual dan audio yang responsif. Ketika pemain memasukkan sampah ke tempat yang benar, skor bertambah dan efek suara positif diputar.

Spesifikasi Teknis Gameplay

  • HTML5 Drag & Drop API / Touch Events: Memungkinkan kelancaran interaksi baik di perangkat Desktop (mouse) maupun Smartphone / Tablet (sentuhan jari).
  • Dynamic Timer & Combo Streak: Sistem waktu mundur dengan multiplier bonus poin jika pemain berhasil memilah sampah secara beruntun tanpa kesalahan.
  • Web Audio API: Sound effect unik untuk feedback benar, salah, dan game over.
  • LocalStorage Persistence: Menyimpan skor akhir secara otomatis dan menampilkan ranking secara real-time.
