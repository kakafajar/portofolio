Detail: Formation IGO Drying

Deskripsi Projek

Sistem ini dirancang untuk menggantikan checksheet manual dalam proses pengeringan (drying) pada mesin IGO. Fitur utamanya mencakup:

  • Input data temperatur dan kelembaban secara digital.
  • Validasi data otomatis sesuai standar parameter produksi.
  • Dashboard monitoring status mesin untuk Group Leader.
  • Riwayat data yang terorganisir untuk kebutuhan audit kualitas.

Teknologi yang Digunakan

PHP CodeIgniter MySQL JavaScript

Detail: APD Monitoring Dashboard

Deskripsi Projek

Projek ini berfokus pada visualisasi data kepatuhan penggunaan Alat Pelindung Diri (APD) di lingkungan pabrik.

  • Sistem alert untuk area dengan tingkat pelanggaran tinggi.
  • Penyederhanaan input data inspeksi harian.
