Detail: Skill Map & Henkaten Board MP

Deskripsi Projek

Sistem terpadu untuk pemetaan kompetensi operator Man Power (Skill Map) yang terintegrasi secara real-time dengan Henkaten Control Board pada line produksi.

Fitur Utama & Penjelasan Modul

  • Skill Map & Assessment Competency: Penilaian tingkat kemahiran operator per Sub Section (seperti Formation) dari rentang 0%, 25%, 50%, 75%, hingga 100% untuk berbagai kompetensi teknis (Proses AGV, Sisir Plate CM, SOP, Loading Plate (+)).
  • Henkaten Control Board 4M: Papan kontrol visualisasi manajemen perubahan 4M (Man, Machine, Method, Material) di area produksi.
  • Man Power Attendance & Assign Board: Monitoring tingkat kehadiran operator per shift (Shift 1, 2, 3) serta pelacakan status absensi (Annual Leave, Sick, Paid Leave).
  • Pattern WO & Job Desk GL: Integrasi pola Work Order dan petunjuk kerja Group Leader untuk mempermudah penempatan staf secara presisi sesuai matriks keahlian.

Teknologi yang Digunakan

PHP CodeIgniter MySQL JavaScript / Tailwind

Detail: Laporan Harian APD

Form APD Ballmell (100% Sesuai)
Form APD Mixer (Evaluasi Item)

Deskripsi Projek

Sistem input digital laporan harian pemeriksaan kelengkapan Alat Pelindung Diri (APD) untuk operator lantai produksi (Ballmell, Mixer, dll) yang diisi setiap hari guna menjaga standar keselamatan kerja (K3).

Fitur Utama & Spesifikasi Modul

  • Checklist APD Visual Per Operator: Pengecekan item spesifik operator (Topi/Helm, Masker Respirator Debu, EarPlug, Sarung Tangan Katun/Latex, Safety Shoes, Apron, Back Support).
  • Persentase Compliance Real-time: Kalkulasi otomatis persentase kepatuhan APD (contoh: Operator 100% Sesuai, Operator 75%).
  • Indikator Validasi Item: Notifikasi visual otomatis (ITEM SESUAI warna hijau) untuk setiap opsi APD yang diinput.
  • Penyimpanan Harian: Rekapitulasi laporan audit K3 harian per shift dan per pos kerja operator.

Teknologi yang Digunakan

PHP CodeIgniter MySQL JavaScript / Tailwind

Detail: Checksheet Produksi Pasting

Deskripsi Projek

Formulir digitalisasi checksheet produksi untuk proses pasting baterai (Form-PR1-LPP-006). Menggantikan pencatatan kertas dengan sistem validasi nilai standar otomatis untuk mempermudah deteksi dini anomali produksi.

Fitur Utama & Indikator Standar (OK / NG)

  • Indikator Visual OK / NG (Not Good): Setiap input parameter memiliki rentang standar otomatis (misal: Grid Feed Standar 1.5 - 7.0). Apabila nilai yang diinput di luar batas (seperti 15.00), kolom input akan otomatis disorot warna merah (NG) sebagai peringatan.
  • Parameter Mesin & Operasional: Pencatatan real-time untuk Grid Feed, Hopper, Motor, Speed, Temp. Ruang Farner, dan Suhu Mesin Oven.
  • Pemeriksaan Kadar Air & Berat Plate: Evaluasi persentase sampel H2O serta penimbangan sampel berat plate secara akurat.
  • Pengukuran Tebal Frame & Cek Visual: Pengukuran presisi tebal frame (Atas, Kanan, Kiri, Bawah) dan tombol toggle pemeriksaan fisik (kontaminasi oli, perataan serat, sirip/salur, retak) dalam status OK atau Not OK.

Teknologi yang Digunakan

PHP CodeIgniter MySQL JavaScript / Tailwind

Detail: Checksheet Formation

Form-PR1-FRM-001 Checksheet Formation
SPGR Monitoring & Daily Trend

Deskripsi Projek

Digitalisasi formulir checksheet harian pada proses formation baterai (Form-PR1-FRM-001 Checksheet Formation Record LINE) terintegrasi dengan popup SPGR Monitoring real-time.

Fitur Utama & Modul Pengecekan

  • Checksheet Formation Record LINE: Input data produksi harian per shift, gedung formation, Kasie, Group Leader (GL), serta penentuan tipe & pasangan loading line.
  • Pilih Line Formation: Pemilihan visual line produksi (Line 01 - 20) dengan indikator status warna real-time.
  • SPGR Monitoring & Trend: Monitoring nilai SPGR terkini (Standard 1.005 - 1.060), jadwal kuras, serta visualisasi grafik Daily SPGR Trend (Daily & Monthly).

Teknologi yang Digunakan

PHP CodeIgniter MySQL JavaScript / Tailwind
